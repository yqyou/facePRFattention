## Attention Improves Population Codes by Warping Neural Manifolds in Human Visual Cortex

## About

This repo contains code for analyzing the attention effects on human fMRI BOLD signals.

## Required Python environment

The Python notebooks were organized for a Python 3.11 scientific computing environment. The recommended setup is through conda:

```bash
conda create -n faceprfattention python=3.11 -y
conda activate faceprfattention
pip install -r requirements.txt
```

## Overview

The main source files are the following:

`/analysis/` contains scripts for analyzing human fMRI data.

* `/script/` contains code for formal data analysis.

  * `cal_matrices.ipynb` contains code for both individual- and population-level analyses. Running this notebook on the example dataset in the `/exampledata/` directory reproduces the expected outputs provided in `/expectedoutput/`.
  * `select_voxels.ipynb` contains code for voxel selection procedures. This notebook cannot be run directly because the original raw data are not included in this repository; however, example output data are provided in `\exampledata`.

  * `/pRF_model/` contains code for fitting voxel receptive field models. These MATLAB scripts cannot be run directly because the original raw data are not included.

* `/exampledata/` contains an example human fMRI dataset (2 subjects * 3 ROI).
* `/expectedoutput/` contains the expected analysis results generated by `cal_matrices.ipynb`

`/plot_figures/`: contains scripts and data for plotting the figures in the manuscript.

* `/scripts/` contains scripts for generating the manuscript figures.
* `/data/` contains data used for figure plotting.

* `/figures/` contains figures produced by the scripts.

## Repository Structure

The main source files are organized as follows:

---

### 📁 `/fmri_analysis/`

Contains scripts and data for human fMRI analysis.

#### `/script/`
Code for formal data analysis:

- **`cal_metrices.ipynb`**  
  Performs individual- and population-level analyses. Running this notebook on the example dataset in `/exampledata/` reproduces the expected outputs in `/expectedoutput/`.

- **`select_voxels.ipynb`**  
  Implements voxel selection procedures. This notebook cannot be run without the original raw data; example outputs are provided in `/exampledata/`.

- **`session_agg.ipynb`**  
  Organizes data by scanning session to examine representational drift. This notebook cannot be run without the original raw data; example outputs are provided in `/exampledata/`.

- **`/pRF_model/`**  
  MATLAB scripts for fitting voxel receptive field (pRF) models. These scripts cannot be run without the original raw data.

#### `/exampledata/`
Example fMRI datasets (2 subjects × 3 ROIs).

#### `/expectedoutput/`
Expected outputs generated by `cal_metrices.ipynb`.

---

### 📁 `/beh_analysis/`

Behavioral analysis for the main experiment (face and digit 1-back task).

- **`behperf.m`**  
  MATLAB script for processing raw behavioral data (not included in this repository; not directly runnable). All results are provided in `behperf_results.mat`.

---

### 📁 `/eye_analysis/`

Eye-tracking analysis for the main experiment (face and digit 1-back task).

- **`eyetracking.ipynb`**  
  Preprocesses raw eye-tracking data (not included in this repository; not directly runnable) and extracts features.  
  All results are provided in `/eye_results/`.

---

### 📁 `/plot_figures/`

Scripts and data for generating manuscript figures.

#### `/scripts/`
Figure generation scripts.

#### `/data/`
Data used for plotting figures.

#### `/figures/`
Output figures generated by the scripts.
